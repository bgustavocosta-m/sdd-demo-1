# sdd-demo-1

Online tic-tac-toe rooms, peer-to-peer, hosted on GitHub Pages: https://bgustavocosta-m.github.io/sdd-demo-1/

```sh
nvm use      # Node 22
npm install
npm run dev  # http://localhost:5173/sdd-demo-1/
npm test
npm run build
```

Pushing to `main` deploys via `.github/workflows/deploy.yml`.
